---

## Reporting a Vulnerability

The QuizPro project takes security and data safety seriously.

If you discover a potential security vulnerability, **please do NOT open a public GitHub issue**.

Instead, please report vulnerabilities responsibly:
1. **GitHub Security Advisories**: Use the private vulnerability reporting feature on GitHub if available.
2. **Private Maintainer Contact**: Contact the repository maintainers privately via GitHub profile contact options.

### What to Include
- Detailed description of the issue
- Minimal steps to reproduce or proof-of-concept
- Affected platform(s) and operating system
- Potential impact or mitigation suggestions

### Response Timeline
- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will provide a status update and estimated resolution timeline within 7 days.
