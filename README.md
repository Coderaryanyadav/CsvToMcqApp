# 📊 CsvToMcqApp

A powerful, elegant Flutter application designed to transform CSV files into interactive MCQ exams. Streamline your learning process with automated exam generation, detailed analytics, and a premium user experience.

## ✨ Key Features

*   **⚡ Smart CSV Import:** Seamlessly import MCQ questions from CSV files.
*   **📱 Interactive Exam Engine:** Take exams in a beautiful, responsive interface.
*   **📈 Advanced Analytics:** Track your performance with detailed statistics and metrics.
*   **📂 Local Storage:** Your exams and results are saved securely on your device.
*   **🎯 Practice Mode:** Focus on learning with instant feedback and audit trials.
*   **🧪 Robust Testing:** Fully tested core logic for reliability.

## 🚀 Getting Started

### Prerequisites

*   Flutter SDK (3.0.0 or later)
*   Dart SDK (2.18.0 or later)

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/Coderaryanyadav/CsvToMcqApp.git
    cd CsvToMcqApp
    ```

2.  **Install dependencies:**
    ```bash
    flutter pub get
    ```

3.  **Run the application:**
    ```bash
    flutter run
    ```

## 🛠 Project Structure

*   `lib/models/`: Core data structures (Exam, Question, Performance).
*   `lib/screens/`: UI components and screens for home, exam, results, and statistics.
*   `lib/services/`: Business logic for CSV parsing, local storage, and analytics.
*   `assets/samples/`: Example CSV and JSON files to get you started.
